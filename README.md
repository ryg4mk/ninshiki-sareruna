# 認識されるな

スマートフォン縦画面向けの、1画面ステルス脱出ゲームです。1ステージにつき敵は1体。壁・箱・柱の陰に隠れながら、光る「EXIT」へ向かってください。鍵・アイテムはありません。

## 遊び方

- **スマートフォン：** 画面下の仮想スティックを倒して、🧍 を移動。指を離すと停止します。
- **PC：** WASD または矢印キーで移動します。
- 敵が **😁 ＋ 👆 👉 👇 👈** のときは巡回中。黄色い視界を避けましょう。手は顔の周りを時計回りに移動します。
- 見つかると **🫪 ＋ 🫵×4** に変化し、高速追跡が始まります。追跡中も出口へ到達すればクリアです。
- 3種類の固定ステージからランダムで開始。開始位置・出口位置・敵位置・敵の向きと巡回に毎回変化があります。
- クリアタイムと最速記録（BEST）を表示。BESTはブラウザ内の `localStorage` に保存します。
- 音声は **起動時ミュート**。🔇 / 🔊 ボタンでいつでも切替できます。
- 「もう一回」で新しい組み合わせを再抽選します。

## GitHub Pagesで公開

1. このZIPを展開し、`index.html`・`style.css`・`game.js`・`README.md` を同じディレクトリに置きます。
2. GitHubのリポジトリへ4ファイルをアップロードします（`main` ブランチのルート推奨）。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選び、`main` と `/(root)` を指定します。
4. 表示された公開URLへスマートフォンなどからアクセスしてください。`index.html` をPCのブラウザで直接開いても遊べます。

外部ライブラリ、画像、音声、フォント、サーバー、ビルド工程は不要です。音声はWeb Audio APIで生成します。絵文字の外見はOS/ブラウザに搭載された標準の絵文字表示に依存します。
